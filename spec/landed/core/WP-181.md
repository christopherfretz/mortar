# WP-181 (RL-1): `-r` code step 0 (types, rows, names, modules, entry points)

The cut is record `spec/landed/layout/WP-154.md` §F; the verifier's and
the lane's side is record `spec/landed/plumb/WP-180.md`. This package
adds types, data, names, empty modules and refusing signatures. No `-r`
behaviour: `-r` stays refused (`unsupported option: -r`) until RL-7, and
a final link writes the same bytes (`cargo xtask static-identical`).

`NO_INPUT_OF_A_KNOWN_MACHINE`, `GCC_LTO_SECTIONS`), the notes

`refused_with_r`, `refused_z_with_r`, `refused_relocatable_output`,

no new class. §4.4 is now a checked table:
`crates/mortar_diag/tests/spec_tables.rs
relocatable_rows_match_the_spec_table` compares the ids, the kind or
class, every text that is not "as in a final link" (built and rendered),
the notes, the lists and the "until" column.

**Not built as written:** `eh-frame-terminator` (the last row, C-R6,
Q7's ruling, RL-11). §4.4 calls it a **warning** with an id, but it is
not a kind of §3.1, and §4.4 also says "No new kind … §3.1 and §4.1 do
not change": two readings. It needs a §3.1 row (with its fields: the
input, the number of records after its terminator) or a rewording as a
note of an existing kind. `ROWS` marks it `Entry::NotBuilt`, and the test
fails once the id becomes a kind, so the row is then built.

## E. What a final link now does that it did not

Nothing observable: `cargo xtask static-identical` shows 0 differ. In the
code:

- `-Ur`, `-d`/`-dc`/`-dp`, `--force-group-allocation` and `--unique` set
  `Plan.ur`, `define_common`, `force_group_allocation` and `unique`
  instead of a `plan.other` entry. Each row is refused in a final link
  (status `refused`), so no link that reads them gets that far.
- Every `Placement` carries `kind: Loadable`, and `Layout::validate`
  reads it before its checks.
- A `Group` chunk (none exists in a final link) is named `.group` and has
  no output section.
- The map has a `relocatable` field, `None`, rendering nothing.
- `docs/status/options.md` has the "At `-r`" column and its counts line.
