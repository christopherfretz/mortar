# WP-246 (V-2): the names of `.symtab`'s entries are judged

Verifier package. Base a828a3de (seam 5, after WP-222). It was written
from the specs and from the outputs. No linker crate was read.

The defect: an incremental-mode output (WP-217's `t1/inc.bad`, AArch64,
glibc, static) named the middle of `__libc_single_threaded` (`readed`)
at `.symtab` entry 2489, and left four `STT_FILE` entries unnamed
(entries 32, 52, 60, 3140). The base verifier gave `findings: 0` and
`linker-defined symbols not judged: 1 (readed)`. This tree gives 15
findings on it, and none on the fixed `inc` and the `plain` link.

## 2. The rules (`spec/plumb.md` §6.5)

- **Y5, the closed set.** A defined output symbol whose name no input
  defines and Y5's table does not value is a finding (`.symtab entry i
  ('n') is defined, but no input symbol has the name and no rule names it
  the linker's (resolve.md §8.1)`), unless it is in the closed set:
  - resolve.md §8.1's rows, layout.md L-105's `__tdata_start`,
    `__start_X`/`__stop_X`;
  - AArch64: S-80's veneer and patch names and the mapping symbols
    `$x`, `$d`, `$x.…`, `$d.…`;
  - a `--defsym` key;
  - each reference linker's own, with the source of each in the table
    of §3;
  - a name `.dynsym` has, or its base before `@` (stage 3 judges it);
  - any name when the line has a script, or when there is no line
    (both listed with the reason).

  Also findings: an unnamed entry that is not `STT_SECTION` or
  `STT_FILE` (`.symtab entry i (st_info …, value …) has no name`), and an
  undefined entry whose name no input and the line do not name
  (`.symtab entry i ('n') is undefined, and no input mentions the
  name`).
- **Y6, the locals of each input file, under mortar's map.** The kept
  locals (S-76, S-78, S-83) are compared with the output's locals as a
  multiset keyed by name, `st_info`, `st_other`, `st_size`, `st_value`,
  and the entry's section must hold the input's section. A kept local
  with no entry: `the local 'n' (file entry k, st_info …) is not in
  .symtab (synth.md S-76)`. An output local that is no kept input's, no
  demoted global and none of the linker's: `.symtab entry i ('n', st_info
  …) is no kept input local (synth.md S-76)`.
- **Y7, file symbols.** `.symtab entry i is an STT_FILE with no name`;
  `.symtab entry i is an STT_FILE named 'n', which no input's STT_FILE
  has (synth.md S-83)`.

Two summary lines are added (`xtask/src/plumb.rs` is unchanged; the
lines come from `Report::summary`):

```
input locals (Y6): kept k (missing m), dropped by rule d; output locals: not a kept input's x, demoted y, the linker's z; STT_FILE judged f
input locals not judged: <reason>: <n>; ...
```

## 6. Still not judged, and why

- Y6 under a foreign map: the reference linkers keep locals by their
  own rules (§3).
- Y6 with no line (`every local: the link's -x/-X options are not
  known`).
- Locals of an input `.eh_frame` when the output has one. S-50 drops a
  mapping symbol in a removed record and an interior local no
  relocation names, and Y6 does not read the relocations for this.
- Labels of an empty allocated section without a record (S-123).
- Locals of a section merged without pieces.
- Locals of a section whose place the map does not give.
- Thread-local locals without a usable `PT_TLS`.
- Undefined or common input locals.
- With no line, a defined name nobody has (a `--defsym` may define it;
  GNU ld's map does not record one) and an undefined one (a `-u` may
  name it). Both are listed by name.
- Under lld and mold, a name at an address no listed input section
  occupies.
- Under GNU ld, a hidden definition in an empty input `.eh_frame` (Y3).
- Under lld and mold, an `STT_FILE` of an unlisted file.

- Kiln and hod objects are not among the Y6 fixtures (clang only). The

- The lld/mold member exception is by address: a name at an address no
