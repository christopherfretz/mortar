# WP-029r: the requests of `spec/x64.md` §16, applied

Branch `wp/029r-x64-requests`, cut from main 063f8ac. This package applies the
requests R-1 to R-17 of `spec/x64.md` §16 to the other specs. R-12 (`spec/plumb.md`)
is assigned to WP-028c. Each request is marked in x64.md §16. The package also
makes the code changes the amended specs require in the shared crates:
`mortar_arch`, `mortar_a64`, `mortar_diag`, `mortar_cli`, `mortar_synth` and
`mortar_resolve`. It leaves `mortar_layout`, `mortar_image` and `crates/mortar`
alone, because WP-027c is editing them.

## Corrections to the proposed texts

- **R-4.** Two edits beyond the proposed text:
  - Both follower lists also name `PLTOFF64` after `48 b8`. The proposed lists
    left out the follower of the 22-byte forms, which X-30 lists.
  - A.5 gains the `4c` REX prefix (`REX'`), so that it says x64.md §8.2's bytes.
- **R-6.** X-15 gave the reason as a text that appears in no reason list of
  arch.md §10 or diag.md. It now gives arch.md §10's `E` reasons:
  `recompile with -fPIE`, and `recompile with -fPIC` in `Shared`.
- **R-10.**
  - `-z ibt`, `-z shstk`, `-z ibtplt` and `-z cet-report` keep GNU's targets,
    x86-64 and i386. They are not "x86-64 only": GNU ld takes them for
    `elf_i386`, and i386 is `spec/x86.md`'s.
  - `-z force-ibt` is lld's row, so it has no target (cli.md §4.1).
  - On AArch64 the four GNU rows are `unknown-option` (§2.9), and
    `-z force-ibt` is refused (§4.4).
- **R-13.**
  - A non-alloc `GotRel` raises `GOT_BASE`, so that the base exists even when
    the code the debug entry describes is not live. X-53 now says so.
  - Echo in a64.md §13.2: the a64.md list gains `GOTREL64`/`GOTREL32`.
  - Fill cannot write `DtpRel` until `SymValue` carries the symbol's type, so
    AArch64 refuses `ABS*` against a TLS symbol at a non-alloc place by name
    (`feature`, `absolute relocation against a TLS symbol in a non-alloc
    section`). Before this, it wrote the template address silently.
- **R-16.** A row of accepted behaviour cannot replace a row in §1.2's table of
  refusals. The row is removed from §1.2, and its text becomes a rule of §3.3
  (commons). §2's definition of "common" names the index.
