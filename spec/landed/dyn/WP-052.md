# WP-052: static-pie on AArch64 and x86-64 (WP-M2-SPIE)

Record of WP-052. Scope: the row WP-M2-SPIE of `spec/landed/dyn/WP-040.md`;
`spec/dyn.md` D-1's `StaticPie` column and D-2, synth S-70. static-pie
(`gcc -static-pie`, `-pie` without `-dynamic-linker`, `--no-dynamic-linker`)
is written on AArch64 and x86-64; on i386 it stays refused by name
("position-independent executable output"). Static links are
byte-identical (`cargo xtask static-identical`: 225 links, 0 differ).

## 1. The design: a static scan with the dynamic link's `.dynamic`

D-2: a static-pie is not a dynamic link. Nothing in it is shared, so its
relocations are a static link's in the `Pie` column; only the tables glibc's
`_dl_relocate_static_pie` reads (`.dynamic`, `.rela.dyn`, the null
`.dynsym`/`.dynstr`/`.gnu.hash`) come from the dynamic machinery (the joins,
WP-053/WP-055), reused with `DynKind::StaticPie`.

- Architecture tables: `M1` (`crates/mortar/src/dynamic.rs` `arch_status`).
  The scan runs with `ScanOptions { output: Pie, dynamic: false }`: an
  undefined weak symbol is `Weak0` (0, no record), never `WeakDyn`; an
  undefined strong one is `undefined symbol`.
- `.dynamic`: D-30's rows for `StaticPie` (`mortar_synth::dynamic`, unchanged
  since WP-045): no `DT_NEEDED`, no versions, `DT_DEBUG`, `DT_FLAGS_1`
  `DF_1_PIE` (+ `DF_1_NOW` and `DT_FLAGS` `DF_BIND_NOW` under `-z now`),
  `DT_RELA*`, `DT_RELACOUNT`, `DT_PLTGOT`; no `DT_JMPREL` (no `.rela.plt`).
- No `.interp`, no `PT_INTERP`, no `PT_PHDR` (layout L-67, as GNU ld).
- `_DYNAMIC` is defined (resolve §8.1: "outputs with `.dynamic`"):
  glibc's `libc.a` (`dl-reloc-static-pie.o`) references it, hidden. It is
  the first GOT word (D-32: AArch64 `.got[0]`, x86-64 `.got.plt[0]`).
- `IRELATIVE` (S-70): the IPLT words' `IRELATIVE`s are the last records of
  `.rela.dyn`, in IPLT order (after the `RELATIVE` part and the sorted
  others, D-40); `.rela.plt` is empty and not written; `__rela_iplt_start`
  and `__rela_iplt_end` are not defined, so glibc's `apply_irel` sees an
  empty range (weak 0) and each `IRELATIVE` is applied once, by the
  self-relocation. D-45: an IFUNC's GOT slot or address word gets a
  `RELATIVE` to its IPLT entry, never an `IRELATIVE` of its own.
- TLS: the static tables' local-exec forms; no TLS dynamic record.
