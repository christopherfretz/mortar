A package of measurement and tests (record `spec/landed/dyn/WP-110.md`

with mortar as with the references, and the one real-line refusal met

## 1. The lane tests

`tests/link/dyn/cxx/shared-*.test`, both 64-bit targets, the four
linkers. Each library is linked by the linker of the record; every
`host` runs in each LT-3 pair (a GNU ld host and a mortar host of every
reference's library and of mortar's), each run compared with the GNU ld
pair (LT-5). The references' outputs are the oracle; where they print
otherwise than the test first said, the test was corrected to what all
of them print (the measured facts are in the tests' comments).

**The property table** (property × compiler × target × linker): every
cell passes, bfd, lld, mold and mortar, AArch64 and x86-64, g++ and
clang++ where the column says yes, in every pair; one cell is skipped:
mold's `shared-static-libstdcxx` on x86-64 (the verifier's S9 on mold's
library, §6). Run: `cargo xtask linktest tests/link/dyn/cxx/`: 11 tests,
72 results, 71 PASS, 1 SKIP.

How the tests know that the name comparison is not what passes
`shared-rtti`: they compare addresses, never `type_info::operator==`
(libstdc++ falls back to `strcmp` of the names when the addresses
differ, `__GXX_MERGED_TYPEINFO_NAMES` 0). That the fallback is live is
shown in the same run: two distinct anonymous-namespace types compare
equal under `dynamic_cast` with clang++ (equal name strings), and
unequal with g++ (whose name begins `*`, compared by address).

**Differences between the references** met (recorded in the tests,
none of them a run difference): `UNIQUE` is `<OS specific>: 10` in
lld's and mold's outputs (`EI_OSABI` 0); GNU ld exports its section
symbols and a version script's node names (D-110 items 3 and 4); mold
keeps `libc.so.6` needed and binds `__cxa_finalize@GLIBC_*` where the
others drop the C library under `--as-needed` (D-111, WP-137); for
`-lgcc_s -Wl,--no-as-needed` the three give three `DT_NEEDED` lists
(§4).

**The libraries compared** (`.dynsym` defined set as a set of (name,
type, binding, visibility), the undefined names, `DT_NEEDED` in order,
`DT_SONAME`; every library of the seven tests on both targets): mortar's
equals GNU ld's on all 54 but for GNU ld's version-node symbol `V1` of
`libver.so` (D-110 item 3) and its `STT_SECTION` entries (item 4);
equals lld's on all 54; equals mold's but for mold's `libc.so.6` need
(above). `-static-libstdc++`: 1143 exports (AArch64, g++), 1065
(x86-64), the same set from all four.

## 2. googletest 1.15.2 as shared libraries

Manifest row `[googletest-shared]` (`tests/realbuild/projects/googletest-shared.sh`:
`-DBUILD_SHARED_LIBS=ON -Dgtest_build_tests=ON -Dgmock_build_tests=ON`),
rows `gcc` and `clang`, run by `cargo xtask realbuild --project
googletest-shared`. Cost: about 10 minutes of builds per row (control
and mortar each about 4 to 5 minutes on AArch64 at `-j4`), more when the
runner waits for the load.

gcc row: 76 lines, 76 linked and clean, 0 refused, 0 defects, and 3
probes linked; the 11 `-shared` lines all link; tests: 63 pass with the
control, 63 with mortar, 0 lost. The 11 libraries (`libgtest`,
`libgtest_main`, `libgmock`, `libgmock_main` at `.so.1.15.2`, and
`libgtest_dll`, `libgtest_no_exception`, `libgtest_main_no_exception`,
`libgtest_main_no_rtti`, `libgmock_main_no_exception`,
`libgmock_main_no_rtti`, `libshared_gmock_main`) compared with the
control's: the `.dynsym` defined sets (as sets of name, type, binding,
visibility), the undefined names, `DT_NEEDED` in order, `DT_SONAME`
and the version needs are equal on all 11 (`libgtest` 883 exports,
`libshared_gmock_main` 1043).

clang row: 76 lines, 76 linked and clean, 0 refused, 0 defects, and 5
probes linked; the 11 `-shared` lines all link; tests: 63 pass with the
control, 63 with mortar, 0 lost. The same comparison of the 11
libraries: equal on all 11 (`libgtest` 869 exports,
`libshared_gmock_main` 1029).
