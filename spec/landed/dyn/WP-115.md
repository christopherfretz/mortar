# WP-115: spec step 0 for shared-object output

Docs only. Applies every request of `spec/dyn.md` §18 (the WP-110
design, accepted) into the owning spec as **planned** rules, each with
its milestone and the package that implements it; writes the hod request
H-3 and its `meta.md` amendment R-MT11; writes the supervisor's ruling on
addresses formed before the start of a local object into D-117, with a
re-run and extended probe; closes Q23-Q25; replaces the design's
provisional package names with WP-115-WP-130; and keeps the design's
scratch in `tests/shared-design/`. No crate, `xtask` or test file
changes; `docs/status/options.md` and `docs/BACKLOG.md` are not edited
(the status row text is the WP-110 record's §G.4, the BACKLOG rows its
§D).

Specs without a rule-id series (arch, a64, resolve, model, cli, diag)
get their new rules as numbered subsections or table rows; the others
continue their own series (X-, X86-, S-, I-, O-, IN-, P-D).

## 4. D-117: before the start of a local object

Written after the boundary rule as a known refusal of correct code; the
rule is unchanged (the supervisor's ruling). Re-run of the oracle on the
supervisor's `c-O0.o` gives his numbers (`pre=1 rule=2 ana=0`, hits at
`.text+0xc` (275) and `.text+0x10` (277) against `.data+0x8` in `gvar`).
The probe (`tests/shared-design/sup/probe.sh`, `probe.out`), extended to
Clang 22, Clang 19 and x86-64: 45 objects, 3 refused, all self-GOT:
GCC 14 AArch64 `-O0` by the rule; Clang 22 and Clang 19 AArch64 `-O0`
by the analysis (`.data+0x18 - 8` = the start of exported `gcount`,
which follows the global `gvar`, so not a boundary); every `-O1`-`-Os`
and every gfortran object clean; x86-64 (GCC 14, Clang 22, gfortran 14,
every `-O`) clean: the before-start address is a code `R_X86_64_PC32`
(`.data+0x14` GCC `-O0`; `.data+0x1c` and a register subtract, Clang
`-O0`), not judged on x86; no absolute word and no PC-relative data word
of the kind. Test `shared-pic-before-start` (WP-117 for GCC, WP-119 for
Clang); `[unmeasured]` for WP-117: interior address-valued uses in
self-GOT objects at `-O0` over its corpora. The note: `-fdata-sections`
and `do not form an address before an object` (diag.md §3.4's notes).
