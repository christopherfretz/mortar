## 3. Found while amending (not in the review)

**A leftover `A` that is a second name of `P`.** After a kill between
W4's `link` and `unlink` (the model's 2 outcomes), `A` and `P` name one
inode. POSIX `rename(P, A)` between two names of one inode does nothing
and succeeds, so the next update's W2 would leave `P` named while it
writes the torn bytes, and its `stat(A)` check would pass. IN-77 W2 now
requires the leftover `A` removed first (IN-77d already removes leftovers
before a link's writes; the sentence makes the order binding for W2).
*Test (U-7):* `leftover_aside_same_inode`.
