## 1. The design note (step 1)

### 1.1 What the update writes today, and why `-g` never updates

The update is path (A) (`crates/mortar/src/update/mod.rs`): `run_with`
(mod.rs:179) runs U2 (`detect`), then **`debug_condition`
(mod.rs:190, :1195)**, which ends every update whose changed file has a
non-allocated `.debug_*` section, in its old rows or its new bytes, with
`update-not-implemented (debug)`. Past it, `image_link` (mod.rs:1101)
runs the WHOLE front over the new inputs, and `reference_of`
(mod.rs:281) refills from that front's image (`crate::image::with_link`,
mod.rs:323; `mortar_image::update::refill`, `crates/mortar_image/src/update.rs:140`):
every section of `layout.files` (the changed files, debug sections
included, update.rs:219), every chunk that is not an input-section body
(update.rs:216: headers, synthetic and MERGED chunks, so `.debug_str`
and `.debug_line_str` whole), the build id recomputed over the new
leaves (update.rs:455-468: the note is re-sealed). The update is taken
only in the IDENTITY case (mod.rs:414): the capture of the front equals
the stored state under IN-78's canonical form, so the front's placement
is the stored one and the bytes written are the full link's bytes.
`placement` (mod.rs:629) runs `delta::layout` with `debug: false`
(mod.rs:720), whose result is judged against the front (`judge`,
mod.rs:764) but never written; with a debug section in a changed file
it refuses (`Refusal::Debug`) and the refusal is only recorded (`Why::Refused`).

**Measured (step-1 experiment, `debug_condition` switched off by an
environment variable in a scratch build, not committed).**
- A stable compile directory (gcc 14, AArch64, `-g -O0`, the same-size
  body edit of `tests/incr-update/scenarios/g_same_size_body_edit`):
  the update is TAKEN (`update (InPlace) ranges=2 bytes=592`), byte-equal
  (`cmp`) to `--incremental=full` of the new inputs; the findings file
  says `delta::layout: update-not-implemented (debug)` (G-1 never ran)
  and `M2b-3 materialize: identity hop equal`.
- The lane (`cargo xtask incr-update`): every `-g` hop is `(layout)`,
  `identity: not the stored state: (layout) tables {57: 8}`: the
  `DEBUG_STRS` rows differ, because the lane compiles each object in
  `cache/src/<object key>/` (`tests/l10/build.py` `Cache.compile`), so
  `DW_AT_comp_dir` (`.debug_line_str`) is a NEW string in every version
  (bytes: `readelf -p .debug_line_str` of hop 1's and hop 2's `c.o`,
  `[5] …/cache/src/e9b08bac…` against `[5] …/cache/src/de7d2b78…`). A
  real build compiles in one directory: the lane needs a stable one to
  reach the identity case (1.4, item H-1).

So the whole of "lifting" the identity case is to replace the blanket
refusal by the conditions that must stay, and to make G-1's decisions
BIND and be JUDGED against the front, since in the identity case the
bytes written are the front's.

### 1.3 The refusals that stay, and when

1. **U2, by name (`debug_condition`, rewritten):** IN-55/IN-55a on the
   old version (`split::classify_rows` over the stored `SECTIONS` rows)
   and the new bytes (`split::classify_object`): `debug-name-index`
   (`.debug_pubnames`, `.debug_pubtypes`, `.debug_names`),
   `debug-unit-kind` (type units, `.dwo` sections, DWARF64, an
   unreadable header). Before anything is read past change detection,
   as IN-70 orders.
2. **U7, G-1's own (binding, by name):** `place`'s reasons
   (`debug-growth`, `debug-unit-kind` for a compressed section or a
   headerless `.debug_addr`, `debug-comdat-keeper`, `debug-compaction`,
   `(debug)` for an unknown debug section, a debug output section of two
   chunks, an UNCHANGED file's debug section killed or revived under
   `--gc-sections`), and `strings`' (`debug-str-limit`,
   `debug-compaction`, `new-output-section`). Today a placement producer's
   refusal is only recorded; for G-1 it binds, because G-1 has not been
   judged in the case it refuses.
3. **G-1 did not run** (a changed file with debug sections, and the
   placement was refused before `delta::layout` by another producer, or
   U5 gave no delta): `update-not-implemented (debug)`, recorded.
4. **Not the identity case** (sizes, strings or sections of the changed
   file's debug contributions changed, any growth, a removed file):
   `update-not-implemented (layout)` (the identity check) or
   `(resolve)` (a file left the link: `reference_of`'s file count),
   until the delta's placement is written (M2b-3's wiring), which then
   writes G-1's dead ranges, appended strings and rewritten aranges.
5. A disagreement of G-1 with the front: a FINDING (recorded with both
   answers), falls back `update-not-implemented (debug)`.
