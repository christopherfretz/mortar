## B. Readings and choices

1. **`.gnu.warning` (L-R1).** Measured on AArch64 (GNU ld 2.44, lld
   19.1.7, mold 2.37.1): GNU ld drops the file-level `.gnu.warning`
   and prints it at `-r`, keeps `.gnu.warning.SYM`, and warns at `-r`
   for the references among its inputs; lld and mold copy both and warn
   nothing. mortar copies both and warns nothing at `-r`, so the
   file-level warning reaches the final link. The cost, written into
   L-R1: a reference that the `-r` merges into `SYM`'s own file is
   never warned.
2. **RV-R6 `.symver`**: measured, lld writes the record against
   `vfoo@@V2` and no `UND vfoo`; GNU ld writes a separate `UND vfoo`.
   mortar writes lld's form, as the rule says.
3. **L-R8 item 3**: the option-made `.note.GNU-stack` (no input note)
   has no input position; it comes last before `.symtab`. GNU ld places
   it by its script, so no reference gives this order.
4. **The stack note's body** is empty and the chunk has no piece; the
   check of a `-r` layout allowed only notes with pieces before
   (`mortar_core::check::relocatable`).
5. **`--odr-runtime` at `-r`**: a no-op (C-R2's row already says so);
   `report` and `fatal` give the bytes of the line without it.
