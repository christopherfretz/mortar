# WP-120: the harness for shared-object outputs

Record of WP-120. Scope: `cargo xtask linktest` links a shared object
with each linker, links hosts against each linker's library and runs
them plain, under an `LD_PRELOAD` interposer and through `dlopen`,
comparing every run with the GNU ld pair's, so that what a library binds
and what an interposer preempts (`spec/dyn.md` D-112) is observed; the
census and the real builds count their `-shared` lines. The rules are
`spec/harness.md` "Shared-object outputs", LT-1 to LT-9. mortar refuses
`-shared` until WP-123: the smoke tests are its expected failures naming
that package. Tools: GNU ld 2.44, lld 22.1.8 and 19.1.7, mold 2.37.1,
GCC 14.2.0, glibc 2.41.

## 1. Measured first

**lld 19 on the D-112 table.** The design ran its preemption table
(`tests/shared-design/exp2/bsym2`) with lld 22 only. Run again with
Debian 13's own lld 19.1.7 (the `ld.lld` of `gcc -fuse-ld=lld`) beside
lld 22.1.8, each identified by its `.comment`: all 17 lines, on AArch64
(native) and x86-64 (qemu), print the same with both, 34 of 34 rows; lld
22's rows equal the design's `result.txt`, including x86-64 `dynlist`
(`tv`, `wtv` preempted). Both refuse `--dynamic-list-data`, `-cpp-new`
and `-cpp-typeinfo` as unknown arguments. No per-line difference: the
table holds for both lld releases the lanes use.

**The lane gap WP-118 reports.** No lane has a host with 64 KiB pages,
so no shared-object test runs on one; a library's page-size assumptions
are seen only through the outputs' alignment, not by loading.

## 2. What landed

- `xtask/src/linktest/format.rs`: the `host` step (LT-1, `StepKind::Host`),
  `Test::pair_start` (LT-2), the pair-part rules (`check_pairs`), linked
  fixtures (`Fixture::is_linked`, `LINKED_FIXTURE_PREFIX`, LT-4), and a
  test whose only link is a host against a linked fixture.
- `xtask/src/linktest/engine.rs`: `Pair` (`of`, `dir_name`, `label`),
  `PairState`, `Ran`, `against_baseline` (LT-3, LT-5); `run_steps` split
  into the library part (`run_library`) and the pairs (`run_pair`);
  `linked_fixture` and `prepare` (LT-4; the fixture cache keyed by
  linker); `native_command` and `ENV_PROGRAM` (LT-6); `run_program`
  returns the run's end and output.
- `xtask/src/linktest/spelled.rs`: a `host` line is a link line.
- `xtask/src/census.rs`: `Flavour::Pic`, the variations `shared`,
  `shared-soname`, `shared-ldshared`, the `dlopen` loader, the refusal
  `unsupported option: -shared` in `OUT_OF_M2`, `shared_count` (LT-7).
- `xtask/src/realbuild/outcome.rs`, `xtask/src/realbuild.rs`:
  `Comparison::shared`, `shared_fixed` and their line (LT-8).
- Tests: `tests/link/shared/interpose.test`, `tests/link/shared/dlopen.test`,
  `tests/link/fixtures/shared-hello.fixture`; the unit tests and the end
  to end test listed in the spec's "Tests".

## 3. Not verified

- The census's `-shared` lines were not run as a lane (not in `--quick`;
  their count is unit-tested on recorded lines). A linked line's loader
  path is untested until mortar links `-shared` (WP-123).
- The real-builds lane was not run (another realbuild was running on the
  host); its count is unit-tested on recorded rows.
- i386: the smoke tests are for AArch64 and x86-64.
