# WP-070: the design of the Mason metadata container and the one-definition-rule checks

Design record. The rules are `spec/meta.md` (MT) and `spec/odr.md` (O);
the work-package cut is `odr.md` §13, the requests to kiln and hod §11,
the amendments to other specs §14, the open questions §15. This file
records how the experiments were run and what they printed, so that a
reviewer can re-run them and compare.

## 1. Environment

aarch64 host (12 cores, shared), Debian; g++ 14.2.0 (Debian 14.2.0-19;
also `x86_64-linux-gnu-` and `i686-linux-gnu-` cross), clang/clang++
19.1.7 and 22.1.8, llc 19 and 22, GNU ld 2.44 (`ld.bfd`, and the cross
`x86_64-linux-gnu-ld.bfd`, `i686-linux-gnu-ld.bfd`), lld 19.1.7, mold
2.37.1, binutils 2.44 strip/objcopy/ar, llvm-strip/llvm-objcopy 19,
elfutils 0.192 (`eu-strip`, `eu-elflint`), gdb 16.3, lldb 19.1.7, glibc
2.41, qemu-user 10.0.13; kiln and hod release builds of the workspace
(`.build/target-kiln/release`, `.build/target-hod/release`). Not
installed: gold, patchelf, abidiff, clang 19's ASan runtime.

## 2. The scripts

In `/Volumes/AgentWork/mortar-helper/.build/review-meta/` (uncommitted,
by the WP's rules). `run-all.sh WORK` runs every script into `WORK`
(about 10 minutes) and writes `WORK/<name>.txt`; remove `WORK` by its
explicit path afterwards.

| script | output | spec |
|---|---|---|
| `catalogue.sh` | K1-K16c, 213 lines: case, compiler, linker, order, exit, output | `odr.md` §2 |
| `catalogue2.sh` | K16d, K16e, K17, K18, K18b, K18c; LTO `-Wodr`; ASan | `odr.md` §2 |
| `weakcheck.py` (+ `elfmini.py`) | W1-W5 and F over objects | `odr.md` §8.1 |
| `legal.sh` | B1-B3; the mixed static link; legal shapes | `odr.md` §3 |
| `container.sh` | six encodings × three targets × linkers and tools | `meta.md` §2 |
| `size.sh` | entity counts and container estimates | `meta.md` §10 |
| `dynamic.sh`, `hook/mason_rt.c`, `hook/gentab.py`, `patchelf_mini.py` | note/segment/tag tolerance; the hook's detection and cost; `.preinit_array` order | `odr.md` §10 |

`weakcheck.py` is a throw-away prototype of W1-W5: per COMDAT signature,
the defined symbols of each copy; W1 compares `st_size` of data symbols,
W2 symbol types, W3 a strong non-COMDAT definition against COMDAT
copies, W4 a digest of a data section's bytes and of its relocations
with symbol indices replaced by names, W5 section alignment, F the same
digest for code (information only).

`hook/mason_rt.c` is a throw-away prototype of O-53/O-54 (pairwise, no
k-way merge, `fprintf` instead of `write`, owner `Mason` with a 4-byte
note instead of O-52's `MasonMeta` with 8): one copy linked into each
module; its constructor walks `dl_iterate_phdr`, finds its own module by
the address of a static function, and merge-joins its sorted
`{u64 key, u64 def}` table with every module listed before it.
`MASON_ODR=warn|off`, `MASON_ODR_TIME=1` prints its own time.

## 3. Results (final run)

The numbers in the specs come from the final `run-all.sh` run of this
WP; the summary:

- **catalogue**: every case links silently with all three linkers and
  both compilers; failures at run time as `odr.md` §2's table says (K2
  abort 134 in `b,a`; K6 clang `a,b` SIGBUS 135; K16b, K16c SIGSEGV 139
  everywhere; K16e SIGSEGV under qemu-i386 with all three).
- **catalogue2**: K16d: 5 `ymm` instructions in the linked `sum` when
  `a.o` (AVX2) is first, 0 otherwise, all three linkers. LTO `-Wodr`:
  K4, K5, K7, K16a; nothing for K1, K11. `-Wlto-type-mismatch`: K14,
  K14b. GCC ASan: `odr-violation` for a strong global in two `.so`s,
  sizes 4/8 and 4/4. K18c: g++ `UNIQUE`, clang `WEAK`, the library sees
  1 without `-rdynamic` and 2 with it.
- **weak-catalogue**: W1 on K5 (`_ZTV1B` 48/40) and K6 (`_ZTI1D` 56/24,
  `_ZTV1D` 72/40); W4 on K5, K6, K9; W3 on K13; nothing on K1, K2, K4,
  K7, K8, K11, K12, K14, K14b, K16a-c.
- **legal**: one function's bytes: g++ `-O0` 136 = g++ `-O0 -g` 136
  (same digest), g++ `-O2` 36, clang `-O0` 140, clang `-O2` 152. Mixed
  static link (12 TUs: g++ `-O0`, g++ `-O2 -g`, clang `-O2`, clang
  `-O0`) with 563 extracted `libstdc++.a`/`libc.a` members: 268 symbols
  checked, 5 flagged (4 × W5 alignment 8 vs 1 on `_ZTS*` and
  `_ZSt19piecewise_construct`; 1 × W4 on a `_Sp_counted_base` vtable),
  zero W1/W2/W3, 82 ms in Python. Legal shapes: none flagged;
  explicit instantiation definitions are `WEAK` in a COMDAT group under
  both compilers.
- **container**: `meta.md` §2's table, identical on the three targets
  (the i386 and x86-64 `ld.bfd -r` rows with the cross `ld.bfd`).
- **size**: `meta.md` §10's table.
- **dynamic**: all three encodings run, survive the three strips and
  debug normally under gdb and lldb (lldb needs `settings set
  target.disable-aslr false` in this container: it cannot set the
  personality); `eu-elflint` errors on the unknown note owner and on the
  unknown segment type. Detection: start-up violation → abort 134 with
  the message; `MASON_ODR=warn` → exit 0; `dlopen` of a violating
  library → abort 134. Cost (two runs): 34/37 µs, 321/381 µs,
  3,880/4,485 µs for 4 modules × 1,250 / 12,500 / 125,000 rows. The
  executable's `.preinit_array` runs before its libraries' constructors
  (PIE and non-PIE).

By hand (commands in `odr.md` Appendix A's last paragraph):
`llc-19`/`llc-22 -O0 -filetype=obj` on
`@m = private constant [8 x i8] c"MASNABCD", section ".mason.meta", align 8, !exclude !0`
(+ `@llvm.compiler.used`) give `.mason.meta PROGBITS … E 0 0 8`; `hod

## 4. Mistakes made and corrected during the experiments

Recorded because a re-runner may meet them:

- Debian's GCC links `--as-needed`; a `-Wl,--no-as-needed` placed
  *after* `-l` options does nothing, so the first hook runs loaded no
  library and measured noise. It must precede the libraries.
- `-Wl,-t` names archives, not members; members come from `-Map`.
- GCC at `-O3` clones an inline function into a local `.constprop`
  copy, so K16d needs `__attribute__((noipa))` to keep a shared COMDAT.
- The native objdump cannot disassemble x86; use the cross one.
- The prototype note sat inside the build-id `PT_NOTE`; retyping that
  segment is what the "segment" variant measures.

## 5. Decisions taken in the design (for the reviewer to attack)

- The container is outside COMDAT groups, one unit per TU (`meta.md` §6).
- Records name symbols by anchor, not by string (`meta.md` MT-12; `odr.md` O-4).
- Code bytes are never evidence (B1); W4/W5 are not default checks.
- `ENFORCE` mismatches are warnings; layout differences are the errors
  that name them (`odr.md` O-30).
- The loadable table is a `PT_NOTE` of Mason's own; the hook is a C
  runtime object mortar links in, `.preinit_array` in executables.
- `--no-odr-check` reads no container byte (`meta.md` MT-42).
