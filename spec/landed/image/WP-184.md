## Tests (`crates/mortar_image/tests/relocatable.rs`)

The test file makes the tables itself, because RL-2 and RL-3 run in
parallel with this package. Its `World` is a small model of the two:

- every section of a live object is kept;
- keys resolve strong > common > weak > undefined;
- one output section per (name, type, flags), in first-occurrence
  order;
- each input section is placed at its alignment, in input order;
- `.eh_frame` is S1's synthetic chunk;
- one `SHT_GROUP` per input group.

The model computes its own sizes for the bodies, `.eh_frame`, the
relocation sections and the groups. The sizes of the symbol tables,
string tables and notes come from `relocatable::sizes`.

## Choices the texts left open

- **The group member order (S8).** The members follow the input
  group's member order, which is L-R3's text: each member's output
  section, then that member's relocation section if one exists.
- **`EI_OSABI`.** It is `GNU` when a written symbol is `STT_GNU_IFUNC`
  or `STB_GNU_UNIQUE`, else 0.
- **`e_flags`.** It is `arch.e_flags` over the live objects.
- **The `.eh_frame` header.** `sh_entsize` is the inputs' common one.
- **The undefined global's type.** It is the type the live undefined
  mentions agree on, else `STT_NOTYPE`.
- **The internal file** is not written to the map.
- **The map's `discard` records:**
  - `Dropped(Comdat)` is written as `comdat`;
  - other drops are written as `unspecified`;
  - consumed sections are not listed (the input property notes, which
    are consumed into the synthetic note, among them).

## For RL-7 (the join)

- **Single sources of sizes.** `relocatable::sizes(link)` gives, per
  chunk, the size the image fills. `build_id_plan` and `property_plan`
  (both on `mortar_synth`) are the sources for the two notes.
- **The `.symtab_shndx` decision** is `Sizes::symtab_shndx`.
- **What `write` checks.** It refuses a size difference, and a
  difference in the existence of `.symtab_shndx` or of either note, as
  an internal error.
- **Diagnostics from `PropertyPlan`.** `write` collects them into its
  own collector and returns only the errors. Warnings such as
  `unknown-property` are dropped at `-r`: the join should route them
  to the link's collector.
- **`recheck`** is called for every file before commit.
- **`Written`** at `-r` reports:
  - `jobs` 1;
  - `leaves` `None`;
  - `sealed` and `build_id` only when the id was hashed.
- **The REL path.** `relrel::write` receives the slice of the field
  (`Implicit` width) and the delta, after every chunk is filled.

  beyond the corpus.

  because `-d` is RL-11's.
- **Memory.** The whole file is built in one buffer, as large as the
  output. A windowed fill is a follow-up.
- **The `.symtab` pass is sequential.** Only the locals are gathered
  per file in parallel.
