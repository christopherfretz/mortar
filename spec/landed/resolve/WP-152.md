# WP-152: the options of the input set

`--whole-archive`/`--no-whole-archive`, `-u`/`--undefined`,
`--require-defined`, `--allow-multiple-definition`/`-z muldefs`/
`--no-allow-multiple-definition` and `--start-lib`/`--end-lib` become
`supported`; a script's `EXTERN` becomes a root (a mislink fixed first).
Measured against GNU ld 2.44, lld 22 and mold 2.37 on AArch64, x86-64
and i386 (static on all three, dynamic and `-shared` on the 64-bit two).

## 1. Why the rows were refused

Every phase that honours them existed: the command line's positional
state (`whole_archive`, `lib`), the walk's `WholeMember`/`LazyObject`
files, resolution's roots (`Options::undefined`, `require_defined`) and
`allow_multiple_definition`. Only the status was missing, with three
exceptions found by measuring (sections 3 and 4).

## 3. Code changes (beyond the rows)

- `EXTERN`: `mortar_resolve` `options()` adds every script `EXTERN` name
  to `undefined` with argument index `EXTERN_ARG + i`; `root_text` names
  it `EXTERN(SYM)`; the text map's roots list them (`mortar/src/image.rs`).
- `--require-defined` with only a shared definition: `required-symbol`
  (`What::RequiredSymbol.shared`), as GNU ld.
- A group in a lib region, a lib region in a group: refused by name in
  the grammar (`unsupported feature: ...`), as lld.
- The text map: whole members listed with `(--whole-archive)`; the
  root line's extra blank removed (a correction of an existing line:
  the default entry's member, when `_start` comes from an archive).
- `xtask/src/census.rs`: the `--whole-archive` refusal key left
  `OUT_OF_M2`; `census_m2.rs` counts the 12 clang asan lines as default.

## 4. Decisions and cells for the supervisor

1. `-u nosuch`: GNU ld writes an undefined `.symtab` entry; lld, mold and
   mortar none. No rule decides; recommendation: keep lld's and mold's.
2. `-u K` where only an `--as-needed` shared object defines `K`: GNU ld
   and lld leave it not needed, mold makes it needed without importing
   `K`, mortar makes it needed and imports `K` (D-11 item 2, D-21, and
   the verifier agrees). The references' outputs are judged P-D6 (GNU
   ld, lld) and P-D7 (mold) by the verifier, so that line is linked by
   mortar alone. Candidate anomalies for the references, or a D-11 ruling.
3. `--require-defined` satisfied only by a shared object: GNU ld's error
   implemented (mold accepts). Decided by the conservative rule, pending
   a ruling.
4. muldefs and `--odr`: `spec/odr.md` has no sentence for a clash the
   option allowed; mortar reports nothing. Gap reported, nothing invented.
5. `--start-lib` and groups: refused by name both ways (lld); mold
   accepts. An unclosed region at the end of a line stays accepted.
6. `OUTPUT(file)` in an implicit script (the EXTERN sweep): GNU ld ignores
   it, lld uses it, mold refuses the script; mortar ignores it, as GNU ld.

## 5. Incremental (`spec/incr.md`)

Every incremental link is a full link today (`small-output`, or
`update-not-implemented`); the dry run (`--incremental-report`) was
checked under each option: a member appearing in a whole archive is
`appeared` (not `extracted`), a `--start-lib` object a changed reference
takes or drops is `extracted`/`unextracted`, a muldefs loser's edit is a
changed file with no symbol change, the winner disappearing is
`definer`. A change of any of the options is `options-changed`.

## 6. The unresolved-symbols rows

`--unresolved-symbols`, `--warn-unresolved-symbols`,
`--error-unresolved-symbols`, `--ignore-unresolved-symbol`: resolution
reads them (`tables.rs`, `verdict.rs`) but more than the status is
missing. Opened for a probe (not committed), AArch64:

| shape | GNU ld | mortar (rows opened) |
|---|---|---|
| static, `ignore-all` or `--ignore-unresolved-symbol`, `&miss_fn` | 0 | 0x437000 |
| `-no-pie`, the same | 0 | 0x410000 |
| `-pie`, `--warn-unresolved-symbols` | links (a warning) | error |
| static, `--warn-unresolved-symbols` | 0, a warning | 0, a warning |

They stay `refused`; the nonzero address would be a mislink once open.

## 7. Verifier

Every mortar output of the new tests (113 links on the three targets)
was judged; the only finding is M9: the verifier's mirror of the
option table (`mortar_plumb` `opts.rs`) does not know the opened rows.
`tests/link/xfails` holds one line per test until the mirror is
regenerated; `crates/mortar/tests/options.rs`'s checks pass with M9
filtered and fail on it until then.

## 8. Census

The clang asan lines that carry `--whole-archive` fail at the missing
`libclang_rt.asan_static.a` with GNU ld too on this host, so the census
cannot link them; the gcc asan lines do not use the option.

## 9. Not verified

- A script `GROUP` read inside a `--start-lib` region.
- gdb on x86-64 and i386 for whole members (the test is AArch64 only).
