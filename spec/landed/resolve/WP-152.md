# WP-152: the options of the input set

`--whole-archive`/`--no-whole-archive`, `-u`/`--undefined`,
`--require-defined`, `--allow-multiple-definition`/`-z muldefs`/
`--no-allow-multiple-definition` and `--start-lib`/`--end-lib` become
`supported`; a script's `EXTERN` becomes a root (a mislink fixed first).
Measured against GNU ld 2.44, lld 22 and mold 2.37 on AArch64, x86-64
and i386 (static on all three, dynamic and `-shared` on the 64-bit two).

## 1. Why the rows were refused

Every phase that honours them existed: the command line's positional
state (`whole_archive`, `lib`), the walk's `WholeMember`/`LazyObject`
files, resolution's roots (`Options::undefined`, `require_defined`) and
`allow_multiple_definition`. Only the status was missing, with three
exceptions found by measuring (sections 3 and 4).

## 3. Code changes (beyond the rows)

- `EXTERN`: `mortar_resolve` `options()` adds every script `EXTERN` name
  to `undefined` with argument index `EXTERN_ARG + i`; `root_text` names
  it `EXTERN(SYM)`; the text map's roots list them (`mortar/src/image.rs`).
- `--require-defined` with only a shared definition: `required-symbol`
  (`What::RequiredSymbol.shared`), as GNU ld.
- A group in a lib region, a lib region in a group: refused by name in
  the grammar (`unsupported feature: ...`), as lld.
- The text map: whole members listed with `(--whole-archive)`; the
  root line's extra blank removed (a correction of an existing line:
  the default entry's member, when `_start` comes from an archive).
- A root and a shared object (the follow-up, section 4 item 2):
  resolution's flags `OBJ_REF`/`OBJ_STRONG` (an object's reference, the
  roots excluded); D-11 item 2 reads `OBJ_STRONG`; a key only roots name
  binds a member of N only; `FROM_OBJECT` of a key only roots name that
  stays undefined is off, so it is in neither `.symtab` nor `.dynsym`;
  `What::RootAsNeeded` (`root_as_needed` in `resolve.rs`) refuses the
  split cell after the needed set.
- `xtask/src/census.rs`: the `--whole-archive` refusal key left
  `OUT_OF_M2`; `census_m2.rs` counts the 12 clang asan lines as default.

## 4. Decisions and cells for the supervisor

1. `-u nosuch`: GNU ld writes an undefined `.symtab` entry; lld, mold and
   mortar none. Ruled: accepted, GNU ld's entry a difference (resolve.md
   §16).
2. A root and a shared object. Ruled (the follow-up): a root from an
   option or a script (`-u`, `EXTERN`, `-e`) never makes a library
   needed (GNU ld's manual: `--as-needed` counts "a non-weak undefined
   symbol reference from a regular object file"); the closure is
   unchanged (`first(K)` counts a shared definition, as-needed or not);
   `K` is imported iff a library of the final needed set defines it
   (GNU ld), and written nowhere otherwise; the one cell GNU ld and lld
   resolve differently is refused by name (`root of an unneeded
   --as-needed shared object and an archive member: K`). A first rule
   (the as-needed library ignored as a definer during the closure) was
   withdrawn: it would extract a member where all three references bind
   the library. Measured (AArch64 and x86-64 alike; `-pie`, `-no-pie`,
   `-shared` alike unless said):

   | line | GNU ld | lld | mold | mortar |
   |---|---|---|---|---|
   | `-u K --as-needed -lk` (strong or weak `K`), `EXTERN(K)` | not needed, `K` UND in `.symtab` only | not needed, `K` nowhere | needed, no `K` (`EXTERN` refused) | not needed, `K` nowhere |
   | `-u K --no-as-needed -lk`, `EXTERN(K)` | needed, `K` imported | needed, no `K` | needed, no `K` | GNU ld's |
   | `-u K r.o --as-needed -lk`, `r.o` needs `J` of `libk` | needed, `K` imported | needed, no `K` | needed, no `K` | GNU ld's |
   | the same, `libka.a` after | needed, `K` imported, no member | needed, no `K` | needed, no `K` | GNU ld's |
   | `--as-needed -lk r.o libka.a` | executables: undefined `J` (the library dropped); `-shared`: not needed, member | needed, no `K` | needed, no `K` | needed, `K` imported, no member |
   | `-u K --as-needed -lk libka.a`, nothing else needs `libk` | not needed, member extracted | not needed, `K` nowhere | needed, no `K` | refused |
   | `-u K rk.o --as-needed -lk libka.a`, `rk.o` references `K` | needed, `K` imported | the same | the same | the same |
   | `-u K libka.a --as-needed -lk` | member, not exported (exe) | member, exported (exe) | as GNU ld | as GNU ld; all export it in `-shared` |
   | `-e K --as-needed -lk` | not needed, entry warning | needed, `K` imported | needed, no `K` | not needed, `entry-not-found` (`e_entry` 0, §5.5) |
   | `--require-defined=K`, `K` in the library | error | (no option) | accepted, needed | error |

   mortar's needed list and `.dynsym` (names, bindings, defined or not)
   equal GNU ld's on every line it links, both architectures, all three
   kinds, but for GNU ld's AArch64 `STT_SECTION` entries (D-21).
3. `--require-defined` satisfied only by a shared object: GNU ld's error
   stands (ruled).
4. muldefs and `--odr`: no rule in this package; the spec question is on
   the ODR backlog (ruled).
5. `--start-lib` and groups: refused by name both ways (lld); mold
   accepts. Accepted (ruled). An unclosed region at the end of a line
   stays accepted.
6. `OUTPUT(file)` in an implicit script (the EXTERN sweep): GNU ld ignores
   it, lld uses it, mold refuses the script; mortar ignores it, as GNU ld.
   Accepted (ruled); a row of input.md §15.

## 5. Incremental (`spec/incr.md`)

Every incremental link is a full link today (`small-output`, or
`update-not-implemented`); the dry run (`--incremental-report`) was
checked under each option: a member appearing in a whole archive is
`appeared` (not `extracted`), a `--start-lib` object a changed reference
takes or drops is `extracted`/`unextracted`, a muldefs loser's edit is a
changed file with no symbol change, the winner disappearing is
`definer`. A change of any of the options is `options-changed`.

`--error-unresolved-symbols`, `--ignore-unresolved-symbol`: resolution

missing. Opened for a probe (not committed), AArch64:

| shape | GNU ld | mortar (rows opened) |
|---|---|---|

| `-no-pie`, the same | 0 | 0x410000 |
| `-pie`, `--warn-unresolved-symbols` | links (a warning) | error |
| static, `--warn-unresolved-symbols` | 0, a warning | 0, a warning |

They stay `refused`; the nonzero address would be a mislink once open.

## 7. Verifier

Every mortar output of the new tests (113 links on the three targets)
was judged; the only finding is M9: the verifier's mirror of the
option table (`mortar_plumb` `opts.rs`) does not know the opened rows.
`tests/link/xfails` holds one line per test until the mirror is
regenerated; `crates/mortar/tests/options.rs`'s checks pass with M9
filtered and fail on it until then.

The gate on the final tree (branch cut from int/batch-8 375c912, not
merged with the moved batch): `cargo xtask linktest` 0 FAIL (2940
results); `ci --quick` fmt, clippy, census, mason, sweep and
static-identical ok (189 new AArch64 rows, none changed; 10 new mason
producer rows); `test` fails in three tests only: `options.rs`
`every_audited_row_holds` and `mortar_plumb` `s3_2a_accepted_is_the_options_table`
(the mirror), and `mortar_odr` `the_register_is_the_spec_table`, which
fails on the base too and is fixed on int/batch-8 by dbc59df.

The follow-up's tests meet three verifier rules that still read the
pre-ruling D-11 (the verifier is not this package's to change):

- **P-D6** reads a root (`-u`, `-e`, `EXTERN`) as a strong reference
  that makes an `--as-needed` library needed: it must take its needed set
  from objects' references only (D-11 item 2 as amended), so that GNU
  ld's, lld's and mortar's not-needed outputs pass
  (`dyn/shared/root-as-needed-unneeded`: `xfail(bfd,lld)` and
  `xfail(mortar)`; lld's `reflld` lines of the refused cell too).
- **P-D7** (the import rule) must import a root's name iff a library of
  the final needed set defines it, and accept no entry when none does;
  it found nothing on mortar's outputs, but its rule for a root that
  makes nothing needed must follow D-21 item 1 as amended (an import
  for `-u K` with `--no-as-needed`; lld's no-import a known difference).
- **P-D2** does not model `EXTERN` in a dynamic link ("script word
  'EXTERN' is not modelled"): it must read `EXTERN(SYM ...)` as roots
  (`dyn/shared/root-as-needed-extern`: `xfail(bfd,lld,mortar)`).
- **P-D4** finds mortar's `e_entry` 0 after `entry-not-found` (`-e K`,
  `K` in a library left out) "in no executable PT_LOAD": resolve.md §5.5
  and L-103 make 0 the value (lld's and mold's), so P-D4 must accept 0
  when the entry symbol is undefined (`root-as-needed-unneeded`).

`dyn/shared/root-as-needed` (the lines all agree on) passes the verifier
for all four but M9 (its `xfails` line, as the other tests').

## 8. Census

The clang asan lines that carry `--whole-archive` fail at the missing
`libclang_rt.asan_static.a` with GNU ld too on this host, so the census
cannot link them; the gcc asan lines do not use the option.
