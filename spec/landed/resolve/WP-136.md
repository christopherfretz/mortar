# WP-136 — the place of a definition: no place is never a number

Rule `spec/resolve.md` §10.1 **P-1**, with `spec/model.md` §4.5's
invariant, `spec/image.md` I-124, `spec/synth.md` S-6 (empty) and
`spec/layout.md` L-162. No new diagnostic kind: a reference to a
placeless symbol uses the existing `discarded-section-reference`.

## The mislinks and their root cause

Two silent mislinks (exit 0, the word 0):

1. a GLOBAL `gms` in an empty `SHF_MERGE|SHF_STRINGS` `.rodata.str1.1`;
2. a GLOBAL `gprop` in `.note.gnu.property`;

and a variant: a global in any other dropped section that is not a
COMDAT copy (`SHF_EXCLUDE`, `.note.GNU-stack`, an input build-id note,
`.gnu.warning.*`, debug sections under `-S`, `.llvm_addrsig`,
AArch64 `.ARM.attributes`) stopped with an internal
error (`no live target in the tables`).

`LinkTables::sym_value_of` (`crates/mortar_image/src/link.rs`) ended in
`entry.or(s).unwrap_or(0)`, and the symbol's `live` came from liveness
alone. A `Kept`, live section with no place gave `None`, and `None`
became 0: an empty merge section has no piece, so `value_in` failed
(the `named_symbol` lookup lands outside the section). A
`.note.gnu.property` section is `Kept` and live but `OutOf::Consumed`,
so it has no place. In a dropped section `live` was false, so fill
reached `MissingTerm`. The scan's `dead` held only for `is_kept &&
!is_live`, so it raised no `DiscardedSection` event for any of the
three. The same mislink hit locals: a local in `.note.gnu.property`
was written as its offset in the note (0x4/0x1c/0x20). A local or
section symbol in an empty merge section was refused with "offset
outside the section".

## The rule

**P-1.** Every defined symbol either has a place or has no place by a
named rule. It has a place when its section is `Kept`, live and
assigned to an output section. An empty section has a place. An empty
`SHF_MERGE` section is placed whole (S-6). After a merged input it lies
at the end of the merged chunk (L-162), where GNU ld and lld agree. It
has no place when its section is dropped by a row of §10 or a script,
consumed (`OutOf::Consumed`), collected, or unassigned. A reference to
a placeless symbol gets §6.3's value for the referring section (the
tombstone in debug sections, 0 in `.gcc_except_table`, unchanged).
Anywhere else it is refused as `discarded-section-reference`. The
refusal names the symbol, the referring file and section, and the
defining file and section. An unreferenced placeless symbol is omitted
from `.symtab` and `.dynsym` and is never an error.

**Invariant** (model.md §4.5): no path turns "no place" into a number.

**The predicate** is `mortar_core::place::section_place(resolution,
assignment, liveness, s) -> Result<(), NoPlace>`. `NoPlace` is
`Dropped(DropReason) | Consumed | Collected | Unassigned | Unknown`.
The scan's `dead`, the image's values, `.dynsym` and
`LinkSections::live` all ask it.

**The typed result** is `mortar_image::link::Valued`: `At(u64) | Import
| NoPlace(NoPlace) | Missing`. It has no `Option` accessor. Fill's
`SymValue` of `NoPlace`/`Missing` is not live.

## Callers that defaulted a missing value, and now

| caller | before | now |
|---|---|---|
| `sym_value_of` | `unwrap_or(0)` | `Valued`; `NoPlace`/`Missing` not live (fill: §6.3 value or the scan's refusal) |
| `def_addr` | `Option<u64>` | `def_value` → `Valued` |
| `value_in` / `entry_addr` | `Option` | `Valued`, `place_of` asked first |
| GOT slot `address()` | value or 0 | `None` unless `At` |
| `DynView::symbol` | `.flatten()` | `global_addr` (`At` only) |
| link map | `Some(Some(addr))` | `global_addr` |
| `.rela.dyn` value closure | `t.sym(key).s` | `None` when not live (internal error) |
| thunk (patches) target | value | `None` when not live (internal error) |
| `.dynsym` `Form::Export` | `missing("value")` | placeless exports omitted (`DynSymSource::has_place`) |
| layout's `.dynsym` check | required | not required for `CheckContext::placeless` keys |
| `LinkSections::live` | liveness | `section_place(..).is_ok()` |
| scan `local_facts`/`global_facts` `dead` | `is_kept && !is_live` | `!has_place` |

## Measured class table

The matrix crosses section kinds, symbol kinds and reference kinds.
Symbol kinds: global, weak, local, section symbol with an addend,
global at the section's end. References: data word, debug word, PC-rel,
GOT, `-pie`, `-shared`, export under `-shared`/`-pie`, none. It ran on
aarch64, x86_64 and i386 with GNU ld 2.44, lld 18 and mold, and with
mortar before and after (9120 cells per run). Cells by section kind,
with G = global/weak/end and L = local/section:

The references disagree on every dropped kind. P-1 takes the strictest
reading: a reference that needs an address is refused. The only cells
that changed between the two mortar runs are those of the twelve
placeless kinds. No placed kind changed.

## Tests

- `crates/mortar_core/tests/place.rs`: P-1 on constructed tables (a placed
  section; NEGATIVE: each placeless kind is a typed `NoPlace`; no
  assignment; script discard).
- `crates/mortar_image/src/link.rs` `place_tests`: I-124 (NEGATIVE:
  `NoPlace` is not live and gives no number; `Valued` fill parts).
- `crates/mortar/tests/front_diff.rs`
  `s6_empty_merge_section_is_placed_whole`: an empty merge section is
  `Regular`, placed whole, and a non-empty one stays `Merge`.
- `tests/link/resolve/place-empty-merge.test` (three targets; mold
  skipped): mislink 1's word and PC-rel/GOT agree and are not 0 (static,
  PIE). `.symtab` lists the symbols. An AArch64 shared object exports
  `gms` with a non-zero value. L-162 is checked by `gmid` past `gpre`'s
  string.
- `tests/link/resolve/place-note-property.test`: mislink 2 refused by
  name, with the defining and referring places. The local word is
  refused. The debug word gets the tombstone. With no reference the
  symbol is absent from `.symtab`.
- `tests/link/resolve/place-dropped-global.test`: `SHF_EXCLUDE`,
  `.note.GNU-stack` and build-id globals refused by name (previously
  internal errors). Unreferenced ones are absent from `.symtab` and from
  an AArch64 shared object's `.dynsym`.

Each link test fails with mortar before WP-136.
