# i386

What mortar links on i386 (`EM_386`, ELFCLASS32) since WP-030c, and what
it refuses by name. The rules are `spec/x86.md`; the record is
`spec/landed/x86/WP-030c.md`.

## Linked

Static non-PIE executables (`-static`, the default `-no-pie` image at
0x08048000), from objects of GCC (`i686-linux-gnu-gcc`, `g++`,
`gfortran`) and Clang (`--target=i686-linux-gnu`), at any `-O`, compiled
`-fno-pic`, `-fPIE` or `-fPIC` (the PIC sequences are relaxed for the
executable, x86.md §8, §9): C, C++ (exceptions, `thread_local`, threads),
Fortran; glibc's IFUNCs and the program's own (static IPLT, `.rel.plt`,
`__rel_iplt_start`/`__rel_iplt_end`); every TLS model including
`-mtls-dialect=gnu2`; `--gc-sections`; `-g` (gdb `info line`, breakpoints
by line, locals). `crates/mortar/tests/x86.rs` holds every one of these
to GNU ld's output under `qemu-i386`, and `cargo xtask linktest --arch
i386` runs the link tests.

## Refused by name

| What | Diagnostic | Rule | Until |
|---|---|---|---|
| `-static-pie` and dynamic outputs (`-pie`, `-shared`, a shared object input) | `unsupported feature` / `unsupported option` | x86.md X86-3, R-15 | M2 |
| An `SHT_RELA` section in an `EM_386` object | `unsupported section type: SHT_RELA` | X86-2 | never (the psABI is REL) |
| An input `e_flags` other than 0 | `unsupported feature: e_flags 0x…` | X86-1 | never |
| An image whose last `PT_LOAD` ends above 2^32, a file of 2^32 bytes or more, `PT_TLS` of 2^31 bytes or more | `output too large` | X86-45, layout L-73 | never (ELFCLASS32) |
| Two records at one `r_offset`, or overlapping read windows | `unsupported feature: overlapping relocations` | X86-5, R-13 (b) | never |
| `R_386_TLS_IE_32`, `R_386_TLS_LE_32`, the dynamic types in an input | `unsupported relocation type` | X86-14, X86-20, Q3 | never |
| `-z ibt`, `-z shstk`, `-z ibtplt`, `-z cet-report` | `unsupported option` | cli.md §2.9, R-11 | the CET package |

The verifier (`mortar_plumb`) judges i386 outputs (its table is
WP-028e's, x86.md R-8). `tests/x86.rs` holds every output it links to
zero findings.
